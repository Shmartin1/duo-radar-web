# Duo Radar — live view

Read-only dashboard for Josh's iPhone Duo stock radar: **https://shmartin1.github.io/duo-radar-web/**

The page itself is static. The live data comes from Duo Radar running on Josh's PC, which it reaches through a Cloudflare tunnel. If his PC is off, the page says so and keeps retrying.

Generated by `tools/build-web.js` in the duo-radar repo. Don't edit `index.html` here by hand.
